# Как пользоваться этим гайдом

* Откройте боковую панель слева, чтобы увидеть оглавление
* На многих страницах есть интерактивные сцены. Если рядом со сценой есть кнопки ![Plus](assets/diagrams/plus.png)
и ![Minus](assets/diagrams/minus.png) (масштаб), камеру можно вращать и перемещать.
Левый щелчок с перетаскиванием вращает камеру, правый с перетаскиванием — сдвигает её.

# Что такое Applied Energistics 2?

Applied Energistics 2 добавляет компоненты и механики для решения задач логистики и хранения. Огромную комнату, заставленную сундуками, можно заменить компактной МЭ-сетью, но это только начало.
Applied Energistics задуман так, чтобы работать вместе с другими модами сборки и позволять автоматизировать их. Систему можно настроить так, что одним щелчком она скрафтит все необходимые материалы (и конечный результат) сложной цепочки крафта, или будет поддерживать заданные количества предметов в наличии, докрафчивая их по мере надобности, или просто перемещать предметы по вашей базе.
