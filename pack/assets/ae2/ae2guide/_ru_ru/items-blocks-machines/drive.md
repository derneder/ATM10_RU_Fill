# МЭ накопитель

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../assets/blocks/drive.snbt" />
</GameScene>

МЭ накопитель — это [устройство](../ae2-mechanics/devices.md), в которое устанавливаются [ячейки хранения](storage_cells.md), чтобы использовать их как
[сетевое хранилище](../ae2-mechanics/import-export-storage.md). В нём 10 слотов, в каждый можно установить ячейку.

Если по какой-то причине понадобится, ячейки можно вставлять в его инвентарь и извлекать из него любыми средствами перемещения предметов — например, воронками или шинами AE2.

Его можно поворачивать «<ItemLink id="certus_quartz_wrench" />».

## Светодиоды состояния ячеек

На ячейках в накопителе есть светодиоды, показывающие их состояние:

| Цвет  | Состояние                                                                           |
| :----- | :------------------------------------------------------------------------------- |
| Зелёный  | Пусто                                                                            |
| Синий   | Что-то содержит                                                                |
| Оранжевый | [Типы](../ae2-mechanics/bytes-and-types.md) заполнены, новые типы добавить нельзя     |
| Красный    | [Байты](../ae2-mechanics/bytes-and-types.md) заполнены, новые предметы вставить нельзя |
| Чёрный  | Нет энергии или у накопителя нет [канала](../ae2-mechanics/channels.md)                 |

## Приоритет

Приоритет задаётся щелчком по значку гаечного ключа в правом верхнем углу интерфейса.
Предметы, попадающие в сеть, в первую очередь направляются в хранилище с наивысшим
приоритетом. Если у двух хранилищ или ячеек одинаковый приоритет
и одно из них уже содержит этот предмет, оно будет предпочтительнее любых
других. Любые [размеченные](cell_workbench.md) ячейки в группе с тем же приоритетом считаются уже содержащими этот предмет. Предметы извлекаются из хранилища с наименьшим приоритетом. Такая система приоритетов означает, что по мере вставки и извлечения
предметов из сетевого хранилища хранилища с более высоким приоритетом заполняются, а с более низким — опустошаются.
