# Высекатель

<BlockImage id="inscriber" scale="8" />

Высекатель используется для высечения схем и [процессоров](processors.md) с помощью [прессов](presses.md), а также для измельчения различных предметов в пыль.
Он может принимать как энергию AE2 (AE), так и Fabric/Forge Energy (E/FE). Он может работать с разделением по сторонам: вставка предметов с разных сторон
помещает их в разные слоты его инвентаря. Для удобства его можно поворачивать <ItemLink id="certus_quartz_wrench" />.
Его также можно настроить на автоматическую передачу результатов работы в соседние контейнеры.

Размер входного буфера можно регулировать. Например, если вы хотите снабжать материалами большой массив высекателей из одного контейнера,
лучше выбрать маленький буфер, чтобы материалы оптимальнее распределялись между высекателями (вместо того чтобы первый
высекатель заполнился до 64, а остальные остались пустыми).

4 пресса для схем используются для изготовления [процессоров](processors.md)

## Настройки

* Высекатель можно настроить на разделение по сторонам (как описано ниже) или на приём входных предметов в любой слот с любой стороны — внутренний фильтр сам решит, что куда положить. В режиме без разделения из верхнего и нижнего слотов нельзя извлекать предметы.
* Высекатель можно настроить на выталкивание предметов в соседние контейнеры.
* Размер входного буфера можно регулировать: большой вариант — для отдельно стоящего высекателя, который вы снабжаете материалами вручную; маленький — чтобы массивы из множества параллельных высекателей были эффективнее.

## Интерфейс и разделение по сторонам

В режиме с разделением по сторонам высекатель решает, что куда положить, в зависимости от стороны, через которую вы вставляете или извлекаете предметы.

![Интерфейс высекателя](../assets/diagrams/inscriber_gui.png) ![Стороны высекателя](../assets/diagrams/inscriber_sides.png)

A. **Верхний вход** — доступен через верхнюю сторону высекателя (в этот слот можно как помещать, так и извлекать предметы)

B. **Центральный вход** — доступен через левую, правую, переднюю и заднюю стороны высекателя (в этот слот можно только помещать предметы, извлекать из него нельзя)

C. **Нижний вход** — доступен через нижнюю сторону высекателя (в этот слот можно как помещать, так и извлекать предметы)

D. **Выход** — доступен через левую, правую, переднюю и заднюю стороны высекателя (из этого слота можно только извлекать предметы, помещать в него нельзя)
