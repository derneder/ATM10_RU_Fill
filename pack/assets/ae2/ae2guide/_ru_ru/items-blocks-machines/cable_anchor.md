# Кабельный якорь

<GameScene zoom="6" background="transparent">
  <ImportStructure src="../assets/assemblies/cable_anchor.snbt" />
  <IsometricCamera yaw="195" pitch="30" />
</GameScene>

Небольшие декоративные шипы на кабелях: с их помощью можно не давать кабелям соединяться, делать лестницы из кабелей
или создавать видимость соединения кабеля со стенами вокруг. Также используются для крафта <ItemLink id="facade" />.

Кабельные якоря не дают образоваться соединению на той стороне, к которой они прикреплены.

По ним можно лазать как по лестнице.
