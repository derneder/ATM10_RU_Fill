# Ячейка просмотра

<ItemImage id="view_cell" scale="2" />

Ячейки просмотра используются для фильтрации отображения в [терминалах](terminals.md). Фильтр для них задаётся на <ItemLink id="cell_workbench" />.

Например, вы хотите, чтобы терминал показывал только выбранные каменные строительные материалы. Задайте ячейке просмотра фильтр по этим
материалам и поместите её в терминал — будут показаны только эти предметы.

Ячейки просмотра суммируются: если у вас есть ячейка просмотра для дубовых досок и ячейка просмотра для булыжника, при установке обеих
будут показаны и доски, и булыжник.
