## Именующий пресс

Именующий пресс можно использовать во высекателе для наименования предметов, подобно наковальне.

Чтобы изготовить его, щёлкните правой кнопкой по <ItemLink id="certus_quartz_cutting_knife" /> или
<ItemLink id="nether_quartz_cutting_knife" /> и вставьте слиток металла; затем введите имя, которое
хотите выгравировать на пластине, и просто извлеките готовую пластину. Во высекателе можно использовать
одну или две пластины одновременно; если использовать две, имя будет напечатано комбинацией обоих имён:
сначала из верхнего слота, затем из нижнего.
