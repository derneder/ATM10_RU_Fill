# Руководство

<ItemImage id="guide" scale="8" />

### Это само руководство, которое вы сейчас читаете, — для всех ваших потребностей в освоении AE2.

* Откройте боковую панель слева, чтобы увидеть оглавление
* На многих страницах есть интерактивные сцены. Если рядом со сценой есть кнопки ![Plus](../assets/diagrams/plus.png)
  и ![Minus](../assets/diagrams/minus.png) (масштабирования), вы можете вращать камеру и двигать её.
  Левая кнопка мыши с перетаскиванием вращает камеру, правая кнопка мыши с перетаскиванием — сдвигает вид.
