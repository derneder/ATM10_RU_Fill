# МЭ сундук

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/chest.snbt" />
</GameScene>

МЭ сундук работает как миниатюрная сеть с <ItemLink id="terminal" />, <ItemLink id="drive" /> и
<ItemLink id="energy_acceptor" />. Хотя его можно использовать как крошечную сеть хранения, вместимость всего
одной [ячейки хранения](../items-blocks-machines/storage_cells.md) ограничивает его полезность в таком качестве.

Вместо этого он полезен для работы именно с установленной внутри ячейкой хранения. Встроенный терминал видит
и имеет доступ только к предметам в установленном накопителе, тогда как [устройства](../ae2-mechanics/devices.md)
общей сети имеют доступ к предметам в любом [сетевом хранилище](../ae2-mechanics/import-export-storage.md),
включая МЭ сундуки.

У него 2 разных интерфейса, и предметный транспорт зависит от стороны. Взаимодействие с верхним терминалом
открывает встроенный терминал. Предметы можно вставлять в установленную ячейку хранения через эту грань,
но нельзя извлекать. Взаимодействие с любой другой гранью открывает интерфейс со слотом для ячейки хранения
и настройками приоритета. Ячейку можно вставить и изъять предметной логистикой только через грань со слотом ячейки.

Его можно вращать <ItemLink id="certus_quartz_wrench" />.

У него есть небольшой буфер энергии AE, так что если он не подключён к сети с [энергохранилищем](../items-blocks-machines/energy_cells.md),
вставка или изъятие слишком большого числа предметов за раз может вызвать просадку.

Терминал можно перекрасить <ItemLink id="color_applicator" />.

## Настройки

У МЭ сундука те же настройки, что у <ItemLink id="terminal" /> или <ItemLink id="crafting_terminal" />.
Однако он не поддерживает <ItemLink id="view_cell" />.

## Светодиоды состояния ячеек

На ячейках в сундуке есть светодиод, показывающий их состояние:

| Цвет  | Состояние                                                                        |
| :----- | :------------------------------------------------------------------------------- |
| Зелёный  | Пусто                                                                            |
| Синий   | Есть содержимое                                                                  |
| Оранжевый | [Типы](../ae2-mechanics/bytes-and-types.md) заполнены, новые типы добавить нельзя     |
| Красный    | [Байты](../ae2-mechanics/bytes-and-types.md) заполнены, больше предметов вставить нельзя |
| Чёрный  | Нет энергии или у накопителя нет [канала](../ae2-mechanics/channels.md)                 |

## Приоритет

Приоритеты можно задать, нажав на гаечный ключ в правом верхнем углу интерфейса со слотом ячейки.
Предметы, попадающие в сеть, сначала направляются в хранилище с наибольшим приоритетом.
Если два хранилища или ячейки имеют одинаковый приоритет, предпочтение отдаётся тому, что уже содержит этот предмет,
перед любым другим. Любые [размеченные](cell_workbench.md) ячейки считаются уже содержащими предмет,
если они в одной группе приоритета с другими хранилищами. При изъятии предметов из хранилища они забираются
из хранилища с наименьшим приоритетом. Такая система приоритетов означает, что по мере вставки и изъятия предметов
из сетевого хранилища хранилища с более высоким приоритетом заполняются, а с более низким — опустошаются.
