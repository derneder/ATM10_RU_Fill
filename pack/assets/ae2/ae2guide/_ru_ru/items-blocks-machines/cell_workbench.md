# Верстак для ячеек

<BlockImage id="cell_workbench" scale="8" />

Верстак для ячеек позволяет настраивать [ячейки хранения](storage_cells.md) и <ItemLink id="view_cell" />.

Можно добавлять [карты улучшений](upgrade_cards.md) и настраивать «разметку», чтобы фильтровать,
что будет хранить ячейка.

Предметы и жидкости можно перетаскивать в слоты из JEI/REI, даже если предмета у вас на самом деле нет.

Щёлкните правой кнопкой мыши по контейнеру с жидкостью (например, ведру или резервуару), чтобы задать эту жидкость
в качестве фильтра вместо предмета ведра или резервуара.

## Настройки

В верстаке для ячеек есть несколько кнопок в левом верхнем углу:

*   Можно разметить ячейку по её текущему содержимому
*   Можно очистить разметку ячейки
*   Верстак можно настроить сохранять разметку при изъятии ячейки, что позволяет копировать настройки между ячейками.
