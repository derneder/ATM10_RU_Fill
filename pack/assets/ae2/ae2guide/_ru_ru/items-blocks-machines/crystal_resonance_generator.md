# Кристальный резонирующий генератор

<BlockImage id="crystal_resonance_generator" scale="8" />

Это устройство вырабатывает энергию для вашей МЭ-сети без топлива. Из-за кристаллических колебаний,
которые оно генерирует, в каждой сети можно использовать только один такой генератор. Эти колебания
даже проходят через <ItemLink id="quartz_fiber" />.

**Скорость выработки:** <ae2:ConfigValue name="crystalResonanceGeneratorRate"/> AE/t
