# Сетевой инструмент

<ItemImage id="network_tool" scale="4" />

Сетевой инструмент — модифицированный [гаечный ключ](wrench.md), который также показывает диагностическую информацию о сети и может хранить [карты улучшений](upgrade_cards.md).
Сохраняя способность гаечного ключа быстро разбирать механизмы и снимать [подчасти](../ae2-mechanics/cable-subparts.md)
с кабеля, он не может ничего поворачивать.

В нём есть 9 слотов для хранения [карт улучшений](upgrade_cards.md), и они будут доступны в любом интерфейсе устройств AE2, если инструмент
находится где-нибудь в вашем инвентаре.

Щелчок правой кнопкой мыши по любой части сети покажет окно с диагностической информацией, похожее на то, что появляется при щелчке правой кнопкой по <ItemLink id="controller" />.
Это окно показывает:

*   Количество используемых каналов в сети
*   Переключатель глобальной настройки отображения энергии в AE или E/FE
*   Количество [энергии](../ae2-mechanics/energy.md), запасённой в сети, и максимальную ёмкость сети
*   Количество энергии, поступающей в сеть и расходуемой сетью
*   Список всех [устройств](../ae2-mechanics/devices.md) и компонентов в сети

Это окно также помогает выяснить, являются ли два разных кабеля или устройства частью одной сети, когда вы возитесь с
[подсетями](../ae2-mechanics/subnetworks.md).

## Скрытие фасадов

<a href="facades.md">Фасады</a> будут скрыты, пока сетевой инструмент находится в любой из рук.

Вы можете взаимодействовать с блоками за скрытыми фасадами, не снимая фасады заранее.
