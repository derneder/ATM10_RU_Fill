Русский перевод квестов All the Mods 10, версия сборки 8.4

Игра не читает текст квестов из наборов ресурсов, поэтому файл ru_ru.snbt нужно скопировать вручную. Без этого шага квесты останутся такими, какие они в вашей сборке.

1. Закройте игру.
2. Откройте архив пакета и найдите в нём папку quests_ru. Архив распаковывать целиком не нужно.
3. Откройте папку вашей сборки: config/ftbquests/quests/lang
4. Если там уже есть ru_ru.snbt и вы его меняли, сохраните копию.
5. Скопируйте туда ru_ru.snbt из пакета с заменой.
6. Запустите игру и откройте книгу квестов.

После обновления сборки файл может быть перезаписан или устареть. Тогда повторите эти шаги с файлом из новой версии пакета.
